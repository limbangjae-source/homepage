# 상록한의원 홈페이지

전주혁신도시 상록한의원의 공식 홈페이지 초안입니다. 교통사고 후유증, 근골격계 통증, 비만·다이어트, 입원·회복 관리 정보를 모바일 우선으로 안내합니다.

네이버 블로그의 공개 콘텐츠를 의료 지식 원천자료로 정리해 SEO·AEO형 공식 홈페이지로 구축합니다.

## 원천자료와 작성 원칙

- 원천자료: [홈페이지 원천자료 — 상록한의원](https://sangrok-kmc.notion.site/db810347fd23416092888ce2bdb20f71?source=copy_link)
- 원천자료와 하위 페이지에서 확인된 사실만 사용합니다.
- 원천자료의 `확인 필요` 또는 `적어주세요` 항목은 사실로 사용하지 않고 사이트에도 `확인 필요`로 표시합니다.
- 치료 효과 단정, 전후 비교, 환자 후기, 과장·공포 유발 표현을 넣지 않습니다.
- 공식 확인된 전화번호에는 바로 연결되는 전화 버튼을 사용합니다.

## 현재 상태

- 모바일 우선 단일 페이지 초안 구현 완료
- 한의원 소개, 의료진 소개, 진료과목, 치료 안내, 건강 칼럼, FAQ, 진료시간·오시는 길, 상담 안내 구성 완료
- FAQ 구조화 데이터와 페이지별 한국어 메타데이터 추가
- 빌드 및 서버 렌더링 테스트 통과
- 비공개 미리보기 배포 완료
- 대표 전화번호, 네이버 예약 링크, 365일 진료시간, 의료진 이력 반영
- 홈페이지 기능 범위에 맞춘 개인정보처리방침 페이지 추가

## 공개 전 반드시 확인할 정보

1. 추석 연휴·구정 연휴·크리스마스 등 휴일의 휴진 여부
2. 주소의 최종 표기와 주차 정보
3. 개인정보 보호책임자 또는 개인정보 문의 담당부서의 공식 지정 정보
4. 전화·내원·예약 과정에서 실제 수집하는 개인정보의 항목·보유기간을 반영한 의료기관 전체 처리방침
5. 로고·의료진·한의원 사진의 사용 허가 및 최종 이미지

위 항목이 확인되고 사용자가 명시적으로 승인하기 전에는 공개 배포하지 않습니다.

## 검증 명령

```bash
npm run build
node --test tests/rendered-html.test.mjs
```

로컬 개발 서버는 현재 PC의 Workers 런타임 요구사항에 따라 실행이 제한될 수 있습니다. 이 경우 비공개 Sites 미리보기에서 확인합니다.
